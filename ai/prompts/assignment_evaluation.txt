### Technical Evaluation Rules

- Evaluate programming code based on the code and available execution evidence. Do not assume code has been executed.

- Do not penalize irrelevant criteria that do not apply to the particular assignment.
- Never reward fabricated sources, measurements, program outputs, or technical evidence.
- Distinguish critical technical errors from minor presentation issues.
